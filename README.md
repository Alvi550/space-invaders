# Space Invaders

Una versión arcade y en español de Space Invaders, hecha con HTML, CSS y JavaScript sin dependencias externas de ejecución.

## Cómo jugar

Abre `index.html` en un navegador moderno o sirve la carpeta desde un servidor estático:

```sh
python -m http.server 8000
```

Después visita `http://localhost:8000`.

- **← / →**: mover la nave.
- **Espacio**: disparar.
- **Enter**: iniciar o volver a jugar.

Elimina la flota para avanzar de nivel. Cada nivel aumenta la velocidad y la frecuencia de los disparos enemigos.
